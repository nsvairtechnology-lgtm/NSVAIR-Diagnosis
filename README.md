## 🌟 Overview

**NSVAIR Diagnosis** is an agentic AI healthcare and screening platform developed by **NSVAIR GROUP OF INDUSTRY**. It transforms standard smartphones and personal computers into multi-modal diagnostic stations. 

By leveraging built-in hardware sensors (camera, microphone, accelerometer/gyroscope, and touchscreen), NSVAIR Diagnosis conducts **16 specialized health evaluations** and synthesizes all cross-module findings into one actionable, real-time comprehensive health report.

## ⚡ Key Features

- **Agentic Multi-Agent Synthesis**: An autonomous central AI reasoning agent cross-references findings from all completed modules, eliminates false positives, flags critical red flags, and compiles prioritized health recommendations.
- **Zero-Retention Privacy**: Sensor signals, video frames, and voice recordings are processed in-memory in real time and never retained on remote servers.
- **Downloadable & Shareable Reports**: Export structured health reports (`.txt`, clipboard, or PDF) to share directly with physicians.
- **PWA (Progressive Web App)**: Installable with one tap on iOS (Safari), Android (Chrome), Windows, and macOS for an offline-ready native application experience.
- **Advanced Enterprise SEO**: Complete JSON-LD structured schemas (`Organization`, `WebApplication`, `MedicalWebPage`, `FAQPage`, `BreadcrumbList`, `MedicalBusiness`), OpenGraph and Twitter card dynamic image generation, XML sitemaps, and search engine robot directives.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ (Node.js 20+ recommended)
- npm or bun

### Installation

```bash
# Clone the repository
git clone https://github.com/nsvairtechnology-lgtm/NSVAIR-Diagnosis.git
cd NSVAIR-Diagnosis

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
